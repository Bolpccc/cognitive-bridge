# 从步骤到理由：一个推导对照

仅在陌生推导仍像操作清单时参考。下例由学习场景改写，无原始对话或身份信息。
学习其如何补连接，不复制符号、事实、篇幅或段落顺序到其他任务。

## 上下文与较弱表达

学习者刚问过比值极限和定理的定义，现在问“两次比较具体怎么操作”。
已知 R 在 0 附近二阶连续可导，R(0)=R′(0)=R″(0)=0。
目标是证明 R(x)/x² → 0。不能因定义刚展示过就认定已经掌握。

较弱表达：“对 R(t) 和 t² 用 Cauchy 中值定理，得到
R(x)/x²=R′(ξ₁)/(2ξ₁)。右边还含有 R′，所以再做一次，得到 R″(ξ₂)/2。”

即使公式正确，也没有解释为何比较这些函数，或为何还需要第二次。

## 较合适的讲法

我们要知道的是：R(x) 相对于 x² 是否小到可以忽略。只知道 R(x)→0
还不够，例如 x² 本身也趋于零，但 x²/x² 始终等于 1。
所以困难在于比较两者趋零的相对快慢。

手里的条件说的是 R 在 0 处的导数。要让这些条件帮上忙，就需要把
R 与 x² 的比值联系到导数。Cauchy 中值定理正好提供这座桥：
两个函数在一段区间上的变化量之比，等于某个内部点处的导数之比，
前提是满足连续、可导以及用于作商的非零条件。

先固定一个足够接近 0、但不等于 0 的 x。t 是在这段区间上变化的自变量。
取 U(t)=R(t)、V(t)=t²，因为我们需要比较的正是这两个量。
以 0 和 x 为端点，是因为 R(0)=0、V(0)=0，变化量之比恰好就是目标比值。
x<0 时区间写作 [x,0]；把两个变化量同时反向相减，比值不变。
两函数在闭区间连续、内部可导，且内部的 2t 不为零，所以有

\[
\frac{R(x)}{x^2}
=\frac{R(x)-R(0)}{x^2-0^2}
=\frac{R'(\xi_1)}{2\xi_1}.
\]

ξ₁ 是定理保证存在的内部点，不是我们选定或算出的数，且会随 x 改变。
这一步已经把 R 换成了 R′，接近了已知的导数条件。
但 R′(ξ₁) 和 2ξ₁ 都趋于零，仍不能直接判断这个比值。
需要继续变换的原因是这个困难还在，并非表达式中出现导数就必须继续。

现在 R′(0)=0，分母的函数 2t 在 0 处也为零，因此当前比值又能写成
R′(t) 与 2t 从 0 到 ξ₁ 的变化量之比。再次用同一定理，得到

\[
\frac{R'(\xi_1)}{2\xi_1}
=\frac{R'(\xi_1)-R'(0)}{2\xi_1-0}
=\frac{R''(\xi_2)}{2}.
\]

这次分母变成固定的 2，两个量同时趋零的问题消失了。
ξ₂ 位于 0 与 ξ₁ 之间，因此 |ξ₂|<|ξ₁|<|x|；当 x→0 时，ξ₂ 也趋于 0。
由 R″ 在 0 连续且 R″(0)=0，R″(ξ₂)/2→0，这就证明了原比值趋于零。

两次变换的用途可以收在一句话里：把难以直接比较的余项比值，
转成可由连续性判断的二阶导数值除以常数。

## 使用边界

这里二阶连续可导是所给的充分条件，不宣称它是所有余项结论的最弱条件。
若条件缺失，须重新核实证明，不能补造连续性；不要循环引用待证明的余项结论。
实际回答只展开当前读者需要的部分。已熟悉定理的人可能只需要最后那个连接；
也可用一个紧邻的例子帮助比较，但不必追加整章 Taylor 应用或理解测验。
