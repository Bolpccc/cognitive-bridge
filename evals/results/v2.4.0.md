Implicit activation, cross-conversation effects, and long-term learning are also
unverified. Local availability is established; full visual integration acceptance
is pending.

motion and no-other-horizontal-force assumptions. Internal T cancels from the
whole-system equation but remains in local motion. F=10 is nonzero external
resultant, so total momentum is not conserved. The stated 25% compares two models,
not an empirical error bound for a real rope. The graphic and authored source
contain these same meanings; that source review is not a browser inspection.

Native artifact checks found no external script, stylesheet, image or iframe
assets; diagram checks/export omitted network fonts. The native pages declare
`zh-CN`, standalone figures `zh`. Exported local marker references resolve, CSS
is carried into the SVG, and authored rectangles fit the viewBox. These are
markup/XML checks, not a measured font-size, text overlap, or responsive-layout test.
